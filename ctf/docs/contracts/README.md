# Contracts Directory

## Purpose
Per-plugin contract artifacts defining access policies, audit requirements, command contracts, and deletion rights.

## Contract Types
- `*_ACCESS_POLICY_CONTRACTS.yaml` — Access policy definitions
- `*_AUDIT_CONTRACTS.yaml` — Audit event requirements
- `*_COMMAND_CONTRACTS.yaml` — Command and API contracts
- `*_PROFILE_AND_DELETION_CONTRACT.md` — Deletion and data retention rights

## Baselines
- Cross-cutting baseline files: deny taxonomy, identity handle, etc.

## Adding New Contracts
- Use templates in `docs/templates/` for new contract files.
