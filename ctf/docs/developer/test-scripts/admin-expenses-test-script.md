### EXP-GPU-1 — The RunPod line says whether its figure is measured or an estimate

**Role:** Admin
**Surfaces:** Web (`/admin/expenses`)
**Precondition:** Signed in as an admin. The RunPod line has a typed amount (for example a made-up `$10–$20`).

**Steps:**
1. With `RUNPOD_BILLING_API_KEY` **not** set, open `/admin/expenses`.
2. Find the **RunPod drafting bill** card below the Contributions money goal card.
3. Find the RunPod line under Recurring.
4. Set `RUNPOD_BILLING_API_KEY` in this project's Infisical (never a value from One Percent's project), let Render sync, and reload the screen.
5. Press **Read the bill now**.
6. Find the RunPod line again, and press **Copy as text**.
7. Open the Audit log tab.

**Expected:**
- Step 2: the card says in amber that the bill is not being read because `RUNPOD_BILLING_API_KEY` is not set, and shows no button.
- Step 3: the line shows the typed range with an amber tag "estimate, typed by hand", and the monthly total includes the typed range.
- Step 4: the card says "Not read yet" and shows the **Read the bill now** button.
- Step 5: the button reads "Reading…", then the card shows the last 30 full days, today so far (marked still changing), up to seven recent days with the newest marked "may still change", and the time it was last read.
- Step 6: the RunPod line shows the card's 30-day figure in place of the typed range, not added to it, with a green tag "measured from the RunPod bill, last 30 days". The monthly total changes by the difference only. The copied text carries the same label on the RunPod line.
- Step 7: the newest entry is the bill read, by you.

**Result:** web ☐

### EXP-GPU-2 — Only this product's endpoint is read, and a settled day does not change

**Role:** Admin
**Surfaces:** Web (`/admin/expenses`), GitHub Actions (`Expenses — Read the RunPod drafting bill`)
**Precondition:** EXP-GPU-1 passed. RunPod dashboard access for the shared account.

**Steps:**
1. In the RunPod dashboard, open the billing view for this product's drafting endpoint only (the id at the end of `OLLAMA_BASE_URL`) and note yesterday's amount.
2. Compare it with yesterday's row on the card.
3. Note the amount of a day two or more days back, then press **Read the bill now** again.
4. In GitHub Actions, run **Expenses — Read the RunPod drafting bill** with "Run workflow".

**Expected:**
- Step 2: the two match to the cent. The figure is not the account total, which would include One Percent's endpoints.
- Step 3: the older day keeps exactly the same amount; only today and a day that ended less than three hours ago can change.
- Step 4: the run passes and its summary says how many days were read. No amount appears anywhere in the run's log or summary.

**Result:** web ☐
