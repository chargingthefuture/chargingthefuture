# Artifacts Directory

## Purpose
Holds generated output files from CI and audit processes.

## Performance Reports
- `perf-budget-report.json`: Generated by `performanceBudgetAudit.mjs`
- Structure: Contains metrics, thresholds, and pass/fail status for each budgeted item.

## CI Integration
- Artifacts are used as CI gates to enforce performance and compliance.

## Lifecycle
- Artifacts are generated outputs and should never be manually edited.
